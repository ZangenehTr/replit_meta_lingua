# Meta Lingua -- Self-Hosted Deployment Guide

Complete guide for deploying Meta Lingua on your own server, optimized for Iranian infrastructure.

---

## Prerequisites

| Requirement | Minimum | Recommended |
|-------------|---------|-------------|
| OS | Ubuntu 22.04 LTS | Ubuntu 24.04 LTS |
| CPU | 2 cores | 4+ cores |
| RAM | 4 GB | 8+ GB (16 GB if using Ollama AI) |
| Disk | 20 GB SSD | 50+ GB SSD |
| Node.js | 20.x | 22.x LTS |
| Docker | 24.x | Latest |
| Docker Compose | v2.20+ | Latest |
| GPU (optional) | -- | NVIDIA GPU for Ollama acceleration |

---

## 1. Server Preparation

```bash
# Update system
sudo apt update && sudo apt upgrade -y

# Install Docker
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# Install Docker Compose (v2 plugin)
sudo apt install docker-compose-plugin -y

# Install Node.js 20 (for local builds)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install nodejs -y

# Verify
docker --version
docker compose version
node --version
```

## 2. Clone and Configure

```bash
# Clone repository
git clone <repo-url> /opt/metalingua
cd /opt/metalingua

# Create environment file
cp .env.example .env
```

### Edit `.env` with your production values:

```ini
# ----- Database -----
DB_PASSWORD=<strong-random-password>
DATABASE_URL=postgresql://metalingua:<DB_PASSWORD>@postgres:5432/metalingua

# ----- Security -----
JWT_SECRET=<random-64-char-string>
JWT_REFRESH_SECRET=<different-random-64-char-string>
NODE_ENV=production

# ----- CORS -----
CORS_ORIGIN=https://your-domain.ir

# ----- SMS (Kavenegar -- Iran) -----
KAVENEGAR_API_KEY=<your-kavenegar-key>
SMS_ENABLED=true

# ----- AI (Ollama -- local) -----
OLLAMA_API_URL=http://ollama:11434
OLLAMA_MODEL=llama3.1:8b

# ----- AI Fallback (OpenAI -- optional) -----
# OPENAI_API_KEY=sk-...
# OPENAI_MODEL=gpt-4o-mini

# ----- Payment (Shetab -- Iran) -----
# SHETAB_MERCHANT_ID=<your-merchant-id>
# SHETAB_TERMINAL_ID=<your-terminal-id>
# PAYMENT_CALLBACK_URL=https://your-domain.ir/payment/callback

# ----- Feature Flags -----
DEMO_TEST_ACCOUNTS=false
ENABLE_AI_FEATURES=true
ENABLE_GAMIFICATION=true
ENABLE_VIDEO_COURSES=true
```

Generate secrets:
```bash
openssl rand -hex 32   # for JWT_SECRET
openssl rand -hex 32   # for JWT_REFRESH_SECRET
openssl rand -hex 16   # for DB_PASSWORD
```

## 3. Build and Start

### Option A: Full Docker Compose (Recommended)

```bash
cd /opt/metalingua

# Build all images
docker compose build

# Start all services
docker compose up -d

# Check status
docker compose ps
docker compose logs -f
```

Services started:
- `metalingua-postgres` -- PostgreSQL 16 (port 5432)
- `metalingua-redis` -- Redis 7 (port 6379)
- `metalingua-ollama` -- Ollama AI (port 11434)
- `metalingua-backend` -- Express API (port 3000)
- `metalingua-frontend` -- React SPA via Nginx (port 80)
- `metalingua-nginx` -- Reverse proxy (port 80/443)

### Option B: Without GPU (no Ollama)

If your server has no GPU, remove or comment out the Ollama service in `docker-compose.yml` and set the OpenAI fallback:

```bash
# In .env
OPENAI_API_KEY=sk-...
OLLAMA_API_URL=  # leave empty to skip Ollama
```

### Option C: External PostgreSQL

If you have an existing PostgreSQL server:

```bash
# In .env
DATABASE_URL=postgresql://user:pass@your-pg-host:5432/metalingua
```

Remove the `postgres` service from `docker-compose.yml`.

```bash

# Test
```

## 6. SSL / HTTPS Setup

### Option A: Let's Encrypt (free, automated)

```bash
sudo apt install certbot
sudo certbot certonly --standalone -d your-domain.ir -d www.your-domain.ir
```

Copy certificates:
```bash
sudo cp /etc/letsencrypt/live/your-domain.ir/fullchain.pem nginx/ssl/cert.pem
sudo cp /etc/letsencrypt/live/your-domain.ir/privkey.pem nginx/ssl/key.pem
```

In `nginx/nginx.conf`, uncomment the HTTPS section:
```nginx
listen 443 ssl http2;
ssl_certificate /etc/nginx/ssl/cert.pem;
ssl_certificate_key /etc/nginx/ssl/key.pem;
```

Auto-renewal:
```bash
sudo crontab -e
# Add:
0 3 * * * certbot renew --quiet && cp /etc/letsencrypt/live/your-domain.ir/*.pem /opt/metalingua/nginx/ssl/ && docker compose restart nginx
```

### Option B: Self-Signed (development / internal)

```bash
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout nginx/ssl/key.pem \
  -out nginx/ssl/cert.pem \
  -subj "/CN=your-domain.ir"
```

## 7. Kavenegar SMS Setup (Iran)

1. Register at [kavenegar.com](https://kavenegar.com)
2. Get your API key from the dashboard
3. Create SMS templates for OTP, notifications, and marketing
4. Set in `.env`:
   ```ini
   KAVENEGAR_API_KEY=<your-key>
   SMS_ENABLED=true
   ```

The platform uses Kavenegar for:
- OTP login verification
- Attendance notifications to parents
- Marketing campaign SMS blasts
- Payment confirmation messages

## 8. Shetab Payment Gateway (Iran)

1. Register with a Shaparak-certified PSP (e.g., Saman, Mellat, Parsian)
2. Get merchant credentials
3. Set in `.env`:
   ```ini
   SHETAB_MERCHANT_ID=<merchant-id>
   SHETAB_TERMINAL_ID=<terminal-id>
   PAYMENT_CALLBACK_URL=https://your-domain.ir/payment/callback
   ```

## 9. Backup Strategy

### Database Backup

```bash
# Manual backup
docker compose exec postgres pg_dump -U metalingua metalingua > backup_$(date +%Y%m%d).sql

# Restore
docker compose exec -T postgres psql -U metalingua metalingua < backup_20260310.sql
```

### Automated Daily Backup

```bash
# Create backup script
cat > /opt/metalingua/scripts/backup.sh << 'EOF'
#!/bin/bash
BACKUP_DIR=/opt/metalingua/backups
mkdir -p $BACKUP_DIR
FILENAME="metalingua_$(date +%Y%m%d_%H%M%S).sql.gz"
docker compose -f /opt/metalingua/docker-compose.yml exec -T postgres \
  pg_dump -U metalingua metalingua | gzip > "$BACKUP_DIR/$FILENAME"
# Keep last 30 days
find $BACKUP_DIR -name "*.sql.gz" -mtime +30 -delete
echo "Backup created: $FILENAME"
EOF

chmod +x /opt/metalingua/scripts/backup.sh

# Add to cron (daily at 2 AM)
sudo crontab -e
# Add:
0 2 * * * /opt/metalingua/scripts/backup.sh >> /var/log/metalingua-backup.log 2>&1
```

### Volume Backup

```bash
# Backup all Docker volumes
docker run --rm -v metalingua_postgres_data:/data -v $(pwd)/backups:/backup \
  alpine tar czf /backup/postgres_volume_$(date +%Y%m%d).tar.gz -C /data .
```

## 12. Iran-Specific Considerations

### DNS and Domain

- Register `.ir` domain via [nic.ir](https://nic.ir)
- Use Iranian DNS providers (e.g., ArvanCloud, Cloudflare with Iran support)
- Consider CDN for static assets (ArvanCloud CDN works well domestically)

### Network

- All services run locally (no external API dependencies except optional OpenAI)
- Ollama runs on-premise for AI features (no data leaves the server)
- Kavenegar SMS is Iran-based (domestic routing)
- Shetab payments are fully domestic (Shaparak network)

### Timezone

- Server timezone should be `Asia/Tehran` (UTC+3:30)
- All calendar displays use Jalali (Solar Hijri)
- Backend stores timestamps in UTC; frontend converts to Jalali for display

```bash
sudo timedatectl set-timezone Asia/Tehran
```

### Compliance

- All student data stored on-premise (no cloud dependencies)
- No data transmitted outside Iran (when using Ollama instead of OpenAI)
- SMS verification via domestic Kavenegar service
- Payment processing via domestic Shetab/Shaparak network

## Troubleshooting

| Issue | Solution |
|-------|---------|
| Backend won't start | Check `DATABASE_URL` in `.env`, verify PostgreSQL is healthy: `docker compose logs postgres` |
| Ollama out of memory | Reduce model size: `ollama pull llama3.2:3b` or allocate more RAM |
| SMS not sending | Verify `KAVENEGAR_API_KEY` and `SMS_ENABLED=true` in `.env` |
| Frontend shows blank page | Check Nginx logs: `docker compose logs nginx`. Ensure `VITE_API_URL` points to backend |
| Database connection refused | Wait for PostgreSQL healthcheck to pass, then restart backend: `docker compose restart backend` |
| SSL certificate errors | Verify cert files exist in `nginx/ssl/` and Nginx config points to correct paths |
| Port 80 already in use | Stop other web servers: `sudo systemctl stop apache2` or change Nginx port in `docker-compose.yml` |
| GPU not detected by Ollama | Install `nvidia-container-toolkit` and restart Docker daemon |
