## 2. New Lead

**Farsi:** بخش ورودی جدید (سرنخ)

### Fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| Phone Number (شماره تماس) | Phone | Yes | If contact exists, auto-fills name/lastName/age/gender. If not, operator fills them and a new contact is auto-created |
| Agent (کارشناس) | Auto | Yes | Auto-detect operator |
| Desired Course (دوره مد نظر) | Dropdown | Yes | IELTS, TOEFL, PTE, GRE, GMAT, SAT, Duolingo, BEC, TTC, GE (admin can add/remove) |
| Desired Module (ماژول مدنظر) | Dropdown | Conditional | Only active when course=IELTS (Academic/General English) or course=PTE (PTE Academic/PTE Core) |
| Goal (هدف) | Dropdown | Yes | Dynamic based on course - see Goal Matrix below |
| Course Type (نوع برگزاری دوره) | Dropdown | Yes | In-person (حضوری), Online (آنلاین), Offsite (بسازمانی) |
| Course Format (نحوه برگزاری دوره) | Dropdown | Yes | Private (خصوصی), Group (گروهی) |
| Referral Source (نحوه آشنایی) | Dropdown | Yes | Instagram, Website, Acquaintances, Immigration, SMS, Goftino, Institute Sign, Former Student, Flyer, Billboard, Telegram, Seminar, Email, Online Placement, Faraja (admin can add/remove) |
| Time Limit (محدودیت زمانی) | Number | Yes | Number only; hint: months to reach goal |
| Preferred Branch (شعبه مدنظر) | Dropdown | Yes | Branch names |
| Message (پیام) | Long Text | No | Operator can type long text |
| Status (وضعیت) | Dropdown | Yes | No Response (عدم پاسخگویی), Placement Test (تعیین سطح), Withdrawal (انصراف), Follow-up (پیگیری) |
| Initial Request Date (تاریخ درخواست اولیه) | Date | Auto | |

### Goal Matrix

| GE | IELTS | TOEFL | PTE | GRE | GMAT | SAT | Duolingo | BEC | TTC |
|----|-------|-------|-----|-----|------|-----|----------|-----|-----|
| Starter | 4-5 | 60-80 | 50-60 | 300-320 | 500-600 | 1200-1400 | 90-100 | elementary | Kids |
| elementary | 5-6 | 80-90 | 60-65 | 320-340 | 600-700 | 1400-1500 | 100-120 | pre intermediate | General |
| pre intermediate | 6-7 | 90-100 | 65-79 | - | 700-800 | 1500-1600 | 120-160 | intermediate | IELTS |
| intermediate | 7-8 | 100-110 | 79-90 | - | - | - | - | upper intermediate | - |
| advanced | 8-9 | 110-120 | - | - | - | - | - | advanced | - |

### Status Transitions

- **Withdrawal (انصراف):** Show "withdrawal reasons" field -> card moves to Withdrawal page, removed from current page, full log saved to Logbook
- **No Response (عدم پاسخگویی):** Count incremented per call attempt (via fab call or call button), full log saved to Logbook
- **Follow-up (پیگیری):** Two new fields open:
  - Follow-up Start (date + time) - filled by operator
  - Follow-up End (date + time) - end date = start date, end time = start time + 1 hour (auto)
  - Card removed from this page -> moved to Pre-Placement Follow-up page, full log saved
- **Placement Test (تعیین سطح):** Two new fields open:
  - Placement Start (date + time) - filled by operator
  - Placement End (date + time) - end date = start date, end time = start time + 1 hour (auto)
  - Placement Method field: Online, Phone, In-person
  - Card removed from this page -> moved to Placement Test page, full log saved

## 3. No Response

**Farsi:** پاسخ نداده ها

### Fields

Same fields as New Lead (phone, name, lastName, age, gender, desired course, module, goal, course type, course format, referral source, time limit, branch, message, initial request date)

### Status Options

Same as New Lead: No Response, Placement Test, Withdrawal, Follow-up

### Status Transitions

- **Withdrawal:** -> Withdrawal page + Logbook
- **No Response:** Stays, call count incremented + Logbook
- **Follow-up:** -> Pre-Placement Follow-up page + Logbook (same time fields as New Lead)
- **Placement Test:** -> Placement Test page + Logbook (same fields as New Lead)

## 4. Pre-Placement Follow-up

**Farsi:** پیگیری قبل از تعیین سطح

> **Display: Calendar view (تقویم)**

### Fields

Same core fields as New Lead plus Agent auto-detection.

### Status Options

Same: No Response, Placement Test, Withdrawal, Follow-up

### Special Rules

- **Follow-up color coding by count:**
  - 1st follow-up: Yellow (زرد)
  - 2nd follow-up: Green (سبز)
  - 3rd follow-up: Blue (آبی)
  - 4th+ follow-up: Black (مشکی)
- When status=Follow-up: Creates a NEW follow-up card and the old card changes color
- **Supervisor** role mentioned (سوپروایزر)

### Status Transitions

- **Withdrawal:** -> Withdrawal page + Logbook
- **No Response:** Count incremented + Logbook
- **Follow-up:** New follow-up created, old card color changes + Logbook
- **Placement Test:** -> Placement Test page + Logbook

## 6. Post-Placement Consultation - Call Center

**Farsi:** مشاوره بعد از تعیین سطح مرکز تماس

| Field | Type | Notes |
|-------|------|-------|

| Consultation Status (وضعیت مشاوره) | Dropdown | Withdrawal (انصراف), Registration (ثبت نام), Refer to Counter (ارجاع به کانتر) |

### When Status = Registration (ثبت نام)

Counselor fills:

| Field | Type | Notes |
|-------|------|-------|
| Birth Date (تاریخ تولد) | Date | |
| Father's Name (نام پدر) | Text | |
| Email (پست الکترونیک) | Email | |
| National ID (کدملی) | Text | |
| ID Photo (عکس مدرک شناسایی) | Image Upload | National ID card photo |
| Counselor Notes (توضیحات مشاور) | Text | |
| Registration Type (نوع دوره ثبت نامی) | Dropdown | Private (خصوصی), Group (گروهی), Package (پکیج) |
| Course Level (سطح دوره) | Dropdown | Dynamic based on registration type |
| Registered Sessions (تعداد جلسات ثبت نامی) | Number/Auto | Group=1, Private=operator enters, Package=1 |
| Payment Method (نحوه پرداخت) | Dropdown | Cash (نقد), Card Transfer (کارت به کارت), Online Gateway (درگاه سایت), POS (کارتخوان), Installments (اقساط), Cheque (چک) |
| Course Price (مبلغ دوره/هر جلسه) | Auto | Read from Course Price Definition page |
| Total Amount (مبلغ کل) | Auto | = Sessions * Price |
| Discount Status (وضعیت تخفیف) | Yes/No | |
| Discount Type (نوع تخفیف) | Dropdown | Cash Amount (نقدی) / Percentage (درصدی) - only if discount=Yes |
| Discount Amount (مبلغ تخفیف) | Number | If type=Cash |
| Discount Percentage (درصد تخفیف) | Number | If type=Percentage |
| Total After Discount (مبلغ کل پس از کسر تخفیف) | Auto | Cash: Total - Amount; Percentage: Total - (Total * %) |
| Tax (مالیات) | - | Reserved for future |
| Student Payment (پرداختی زبان آموز) | Number | Filled by operator |
| Remaining Balance (مبلغ باقی مانده) | Auto | = Total After Discount - Payment. **Must be 0 for all methods except Installments/Cheque. Error if negative.** |
| Payment Date/Time (تاریخ و ساعت پرداخت) | DateTime | |
| Tracking Code (کد پیگیری) | Number | Min 4 digits. Shown for all methods except Cash |
| Institute Bank Account (حساب بانکی مجموعه) | Dropdown | From bank accounts page. Shown for all methods except Cash |
| Payment Receipt (تصویر رسید پرداخت) | Image Upload | Shown for all methods except Cash |
| Contract Image (تصویر قرارداد) | File Upload | |
| Student Seniority (قدمت زبان آموز) | Auto | = "Old" if prior purchase found, else "New" |

#### Installment-specific fields:
- Installment Start Time (زمان ابتدایی پرداخت قسط) - DateTime
- Installment End Time (زمان انتهایی پرداخت قسط) - Auto: same date, +1 hour

#### Cheque-specific fields:
- Cheque Delivery Start (زمان ابتدایی تحویل چک) - DateTime
- Cheque Delivery End (زمان انتهایی تحویل چک) - Auto: same date, +1 hour

### Course Level Dropdowns by Registration Type

**Private courses:** A1, A2, B1, B2, C1, C2, FI1, FI2, IPro, Step1, Step2, TPro, GRE, PTE, SAT, GMAT, MSRT, EPT, Duolingo, A1-C2 Ger, Pre PTE, Big English Starter, Teen To Teen 1-4, Big English 1-6, Chemistry, Biology, Math, Science, Literature, Vocabulary & Spelling, Grammar & Writing, Power Point, Geography, History, Physics, Social Study, Ethics, BEC

**Package courses:** Package Exp 1-3, Package Gold 1-3, Immigration Conversation 1-2, Practical Conversation, Conversation On The Trip

**Group courses:** Dynamic from Group Class Definition page, filtered by placement level range, future start date, available capacity

### Transitions After Registration

- Card removed from this page -> **Final Registration** + Logbook
- If Registration Type = Package -> also creates card in **Mentor Assignment** + **Set Private Class**
- If Registration Type = Private -> also creates card in **Set Private Class**
- If Registration Type = Group -> student assigned to selected group class
- If Payment = Installments -> also creates card in **Installments** page
- If Payment = Cheque -> also creates card in **Cheque** page

### Other Status Transitions

- **Withdrawal:** -> Withdrawal page + Logbook
- **Refer to Counter:** -> Post-Placement Consultation (Counter) + Logbook

## Cross-Cutting Rules

### Logbook (لاگ بوک / پیشینه)

Every status change creates a full log entry with ALL populated fields at that moment. This applies to every page transition throughout the pipeline.

### Withdrawal Reasons (دلایل انصراف)

Whenever status = Withdrawal, a "withdrawal reasons" dropdown must appear before the card can be saved and moved to the Withdrawal page.

### Auto-Calculations

- **Follow-up End Time:** Always = Start Time + 1 hour, same date
- **Placement End Time:** Always = Start Time + 1 hour, same date
- **Charge Expiry Date:** Calculated from class days, start dates, sessions per day, based on allowed sessions
- **Remaining Balance:** Must be >= 0 (error if negative: "Enter correct amount")
- **Remaining Balance for non-installment/cheque payments:** Must be exactly 0 (error: "Balance remaining")

### Role Access (implied from document)

| Role | Primary Pages |
|------|--------------|
| Operator (اپراتور/کارشناس) | New Lead, No Response, Pre-Placement Follow-up |
| Supervisor (سوپروایزر) | Placement Test, Set Private Class, Set Class Number |
| Counselor (کارشناس مشاور) | Post-Placement Consultation (Call Center & Counter) |
| Counter Staff (کارشناس کانتر) | Post-Placement Consultation (Counter) |
| Teacher (استاد) | View only: own classes, own attendance |
| Admin (ادمین) | All pages, can add/remove course options and referral sources |
