# Meta Lingua

**Enterprise language-institute management platform with AI-enhanced learning.**

React 18 + TypeScript frontend, Express.js + PostgreSQL (Drizzle ORM) backend.
Self-hosted, bilingual/trilingual (EN / FA / AR), Jalali calendar, indigo `#4F46E5` theme.

---

## Quick Start (Development)

```bash
# 1. Clone & install
git clone <repo-url> && cd meta-lingua
npm install
cd backend && npm install && cd ..

# 2. Environment
cp .env.example .env          # edit DATABASE_URL, JWT_SECRET, etc.

# 3. Start (macOS / Linux)
chmod +x start-dev.sh && ./start-dev.sh

# 3. Start (Windows)
start-dev.bat
```

Frontend: `http://localhost:5173` | Backend API: `http://localhost:5000/api`

## Role-Based Access Control (9 Roles)

The platform uses a **two-layer security model**:

1. **Role Gates** — arrays like `CRM_ROLES`, `STAFF_ROLES`, `FINANCE_ROLES` control route-level access
2. **FACS (Feature Access Control System)** — granular per-feature toggles per role, stored in `feature-permissions-store.ts`

| Role | Access Level |
|------|-------------|
| `admin` | Full platform access, all modules |
| `supervisor` | Academic management, grading, reports, CRM |
| `teacher` | Own classes, attendance, CallerN, earnings |
| `student` | Learning portal, courses, LinguaQuest, CallerN |
| `call_center` | CRM pipeline, lead management, VoIP |
| `mentor` | Assigned students, session summaries, prep briefs |
| `accountant` | Financial reports, invoices, commissions |
| `front_desk` | Registration, scheduling, contact book |
| `marketing` | Campaigns, promo codes, analytics |

## Key Modules

### CRM Pipeline (34 Pages)
Full lead-to-graduation pipeline: Contact Book, New Lead, No Answer, Pre-Placement Follow-Up, Placement Test, Consultation (Call Center + Counter), Withdrawal, No Show, Private/Group Class Setup, Active Classes, Attendance (Online/In-Person/Offsite), Mentor Assignment, Substitution History, Room Assignment, Installments, Charge Extension, Hold Calendar, SPA Cards, QC Cards, Observer, Checks, Final Registration, Completed Classes, Pipeline Analytics, Teacher Availability.

### LinguaQuest (Gamified Learning)
20+ activity types (multiple choice, drag-drop, dictation, conversation, essay, pronunciation, etc.) and 10 mini-games (Synonym Ladder, Error Detective, Debate Flip, Collocation Builder, etc.) with XP, levels, streaks, and leaderboards.

### CallerN (Video Calling)
WebRTC-based 1-on-1 and group video rooms with screen sharing, session recording, and payment integration.

### AI Services
Ollama-first (self-hosted) with OpenAI fallback: grammar checking, essay scoring, speaking evaluation, flashcard generation, homework generation, dropout prediction, attendance anomaly detection, skill radar analysis.

## Project Structure Summary

- **Frontend state**: localStorage-backed mock stores (`src/lib/*-store.ts`) — no additional database tables required for prototyping
- **Validation**: All data flows through Zod schemas (`zodParse` / `zodValidate`) — zero `as any` casts
- **i18n**: `useLanguage()` hook with `{ language, setLanguage, t, isRTL }` — logical CSS only (`ms-`, `me-`, `start`, `end`)
- **Icons**: Strictly Lucide React — no other icon libraries
- **Calendar**: Jalali (Solar Hijri) throughout, with Gregorian conversion utilities
