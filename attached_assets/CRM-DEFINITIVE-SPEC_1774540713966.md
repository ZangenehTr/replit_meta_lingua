### **[NEW — Change 2]** Payment Data Persistence

Before any card movement, ALL financial fields above must be persisted to a `PaymentRecord` in `payment-store.ts`:

```typescript
interface PaymentRecord {
  id: string;
  leadId: string;
  studentId?: string;
  type: 'registration' | 'extension' | 'installment_payment' | 'cheque_clearance';
  courseId: string;
  courseLevel: string;
  registrationType: 'private' | 'group' | 'package';
  sessions: number;
  unitPrice: number;           // from course-pricing-store
  totalAmount: number;
  discountType?: 'cash' | 'percentage';
  discountValue?: number;
  totalAfterDiscount: number;
  paymentMethod: 'cash' | 'card_transfer' | 'online_gateway' | 'pos' | 'installments' | 'cheque';
  amountPaid: number;
  remainingBalance: number;
  trackingCode?: string;
  bankAccountId?: string;
  receiptImageUrl?: string;
  contractImageUrl?: string;
  paymentDateTime: string;      // ISO
  gatewayTxId?: string;         // links to payment-gateway-store transaction
  source: 'staff_consultation' | 'student_self_pay' | 'payment_link';
  createdBy: string;            // userId
  createdAt: string;            // ISO
}
```

```typescript
  maxDiscountAmount?: number;  // Cap for percentage discounts
  minPurchaseAmount?: number;  // Minimum cart value to apply
  applicableTo: 'all' | 'group' | 'private' | 'callern' | 'video_course';
  applicableCourseIds?: string[];  // Empty = all courses
  maxUsageTotal?: number;      // null = unlimited
  maxUsagePerStudent?: number; // Typically 1
  currentUsage: number;
  startsAt: string;            // ISO (Jalali display)
  expiresAt: string;           // ISO (Jalali display)
  isActive: boolean;
  createdBy: string;           // Marketing user ID
  createdAt: string;
}

interface PromoCodeUsage {
  id: string;
  promoCodeId: string;
  studentId: string;
  transactionId: string;       // Links to PaymentTransaction
  discountApplied: number;     // Actual Toman saved
  usedAt: string;
}
```

### Validation Logic (student-facing)

```typescript
function validatePromoCode(
  code: string,
  studentId: string,
  courseType: 'group' | 'private' | 'callern' | 'video_course',
  amount: number
): { valid: true; discount: number } | { valid: false; reason: string; reasonFa: string } {
  // 1. Code exists and isActive?
  // 2. Within startsAt–expiresAt window?
  // 3. currentUsage < maxUsageTotal?
  // 4. Student hasn't exceeded maxUsagePerStudent?
  // 5. applicableTo matches courseType (or is 'all')?
  // 6. amount >= minPurchaseAmount?
  // 7. Calculate discount:
  //    - percentage: min(amount * discountValue / 100, maxDiscountAmount)
  //    - fixed: min(discountValue, amount)
  // 8. Return { valid: true, discount } or error
}
```

### Principle

## 46. Profitability Calculation & Loss Alert

### Formula

```
Class Revenue = Number of Students × Course Fee (from course-pricing-store)
Teacher Cost  = Teacher Rate Per Session × Number of Sessions Held
Profit/Loss   = Class Revenue - Teacher Cost
```

### Loss Alert
When a class's teacher cost **exceeds** its revenue (`Profit/Loss < 0`):
- **Red alert** displayed on the class card in Active Private Classes / Active Group Classes
- Notification to Supervisor + Accountant
- Visible in Pipeline Analytics (Section 30) as a "Loss Classes" metric

### Where Displayed
- Class detail view (staff only)
- Teacher Earnings page (teacher sees their own earnings, NOT the profitability)
- Financial reports (admin/supervisor/accountant)
